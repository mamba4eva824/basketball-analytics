# Scouting reports

Pre-game reports written with the `scouting-report` skill from `/api/matchup`. They're saved here so we can look back at them after the game.

- File name: `YYYY-MM-DD-LAL-at-OPP.md` for road games and `YYYY-MM-DD-OPP-at-LAL.md` for home games. The date is the game date, in US Eastern time.
- Every report states its data source and refresh date. A report built from demo data must say so at the top. Don't commit demo-data reports here.
- Numbers are a snapshot as of the refresh date. Don't edit an old report after new games; write a new one.
